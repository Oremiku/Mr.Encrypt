# 暗号くん
ファイルやテキストなどのデータを暗号化・復号するためのアプリケーションです。

本プロジェクトは、**GitおよびGitHubの使い方を学習すること**を目的として開発しています。

## 概要
「暗号くん」は、ユーザーが指定したファイルやテキストを暗号化し、安全に保存・管理するためのアプリケーションです。

主な目的は以下の2つです。

* ファイルやテキストなどのデータを暗号化・復号する
* Git / GitHubを使用した開発フローを実践的に学習する

## 開発環境

* Windows
* Visual Studio 2022
* C#
* .NET
* Windows Forms
* Git
* GitHub

## Git / GitHubの学習
このプロジェクトでは、実際の開発を想定したGit / GitHubの運用を練習しています。

## ブランチ運用

基本的に以下のようなブランチ構成で開発します。

```text
main
  └── develop
       ├── feature/xxx
       ├── feature/yyy
       └── bugfix/zzz
```

機能追加や修正は専用のブランチで行い、Pull Requestを利用して `develop` ブランチへマージします。

## 注意事項

本アプリケーションは**学習目的で開発しているものです**。

暗号化機能についても、実運用におけるセキュリティを保証するものではありません。

重要なデータや機密情報の保護を目的として使用しないでください。
